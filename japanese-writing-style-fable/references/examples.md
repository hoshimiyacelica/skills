# 添削例

SKILL.md の各基準について、避けたい書き方と望ましい書き方を対にして示します。基準そのものは SKILL.md にあり、このファイルはその適用例をまとめた補足です。

## 目次

本文の節は、この目次の順に並んでいます。

- 記号と書式: 太字をやめる / かぎ括弧と引用符を減らす / 中黒より読点や区切りを使う / 番号を手で振らない / 英数字は半角で書く / 装飾的な見出しを避ける
- 言葉づかい: 助詞を省略しない / 単語を不自然に圧縮しない / い抜き・ら抜きを避ける / 口語を使わない / 文体を統一する / ひらける漢字はひらく / 決まり文句のパターンを繰り返さない / 抽象的な比喩語に頼らない
- 文の構造: 主語と述語をつなげる / 主語と述語の距離を近くする / 文をまたいで主語を統一する / 能動態を基本にする / 体言止めを使わない / 長い文は分ける / 読点を適切に打つ
- 文と文の流れ: 単純接続の「が」を使わない / 接続詞を使いすぎない / 同じ文末を繰り返さない / 文と文のつながりを意識する
- 構成: 段落の構造
- 内容: 推測を事実として書かない / 自信過剰な断定を避ける / 曖昧な表現を避ける

## 太字をやめる

避けたい:

```
**結論**: オンライン授業は移動の負担を減らす。
```

望ましい:

```
結論として、オンライン授業は移動の負担を減らす。
```

強調は記号ではなく、語順や言い回しで示します。

## かぎ括弧と引用符を減らす

避けたい:

```
"対面授業" には「その場で質問できる」という利点がある
```

望ましい:

```
対面授業には、その場で質問できるという利点がある。
```

固有名詞の区別や引用、コードなど、本当に必要な場面だけ括弧を使います。

## 中黒より読点や区切りを使う

避けたい:

```
評価軸は学習効果・運営コスト・満足度の三つである。
```

望ましい:

```
評価軸は、学習効果と運営コスト、満足度の三つである。
```

## 番号を手で振らない

見出しに通し番号を付けると、順序や項目数が後で変わったときに崩れます。

避けたい:

```
## 1. 比較の観点
### 1.1 学習効果
### 1.2 運営コスト
```

望ましい:

```
## 比較の観点
### 学習効果
### 運営コスト
```

本文の段落に番号を手で振る書き方も同様に避け、標準のリスト記法に任せます。

避けたい:

```
1. 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
   そして受講者の満足度から見た評価までを順に検討する。
2. 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

望ましい:

```
- 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
  そして受講者の満足度から見た評価までを順に検討する。
- 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

## 英数字は半角で書く

避けたい:

```
１９６９年に人類は月に到達した。Ｋｉｎｇ Ａｒｔｈｕｒは伝説上の王である。
```

望ましい:

```
1969年に人類は月に到達した。King Arthurは伝説上の王である。
```

横書きでは英数字を半角にします。全角にすると読みづらく、検索にもかかりにくくなります。

## 装飾的な見出しを避ける

避けたい:

```
## 対面授業が私たちに教えてくれること
```

望ましい:

```
## 対面授業の利点
```

見出しは内容そのものを端的に示します。「〜が教えてくれること」「〜という挑戦」のように、もったいぶった言い回しは付けません。

## 助詞を省略しない

避けたい:

```
本稿は対面とオンライン比較し、満足度評価する。
```

望ましい:

```
本稿では対面とオンラインを比較し、満足度を評価する。
```

## 単語を不自然に圧縮しない

避けたい:

```
特定タスク用の最適化を施す。
```

望ましい:

```
特定のタスクに向けた最適化を施す。
```

## い抜き・ら抜きを避ける

避けたい:

```
データは増えてるが、原因はまだ見れてない。
```

望ましい:

```
データは増えているが、原因はまだ見られていない。
```

## 口語を使わない

避けたい:

```
なので、いっぱい必要だ。月一で確認する。
```

望ましい:

```
したがって、たくさん必要だ。月に一度確認する。
```

話し言葉を書き言葉に直します。よくある例:

- なので → したがって、そのため
- いっぱい → たくさん、多く
- やっぱり → やはり
- ちゃんと → きちんと、正しく
- 〜みたいな → 〜のような

## 文体を統一する

避けたい:

```
公園に行きましたが、休日でしたので、人がたくさんいました。しかし、静かな場所もあった。
```

望ましい:

```
公園に行ったが、休日だったので、人がたくさんいた。しかし、静かな場所もあった。
```

だ/である体で統一します。です/ます体が途中で混ざると文章全体の調子が崩れます。

## ひらける漢字はひらく

避けたい:

```
其の事が原因と成り、更に状況が悪化した事は否めない。
```

望ましい:

```
そのことが原因となり、さらに状況が悪化したことは否めない。
```

漢字が続くと読みづらくなります。意味の伝わりに支障がなければ、ひらがなにします。よくある例:

- 事 → こと
- 成る → なる
- 其の → その
- 更に → さらに
- 出来る → できる
- 全て → すべて
- 但し → ただし
- 予め → あらかじめ

## 決まり文句のパターンを繰り返さない

避けたい:

```
この問題を3つの観点から整理する。
第一に、コストの観点から見ると……
第二に、品質の観点から見ると……
第三に、速度の観点から見ると……
```

望ましい:

```
コストが一番大きな問題で、そのうえ品質にも影響が出ている。速度はいまのところ許容範囲にある。
```

「Xつの観点から」「AではなくBだ」のような決まり文句は、一度使うぶんには問題ありませんが、繰り返すと文章全体が型にはまった印象になります。並列する項目に重みの差があるなら、それを文章の構造に反映させます。

## 抽象的な比喩語に頼らない

避けたい:

```
オンライン授業の本質は、学習体験の解像度を変える点にある。教室にはない手触りがそこにある。
```

望ましい:

```
オンライン授業の特徴は、録画を後から見直せたり、チャットで質問できたりする点にある。教室での対面とは進め方が違ってくる。
```

「手触り」「解像度」「〜の本質」のような抽象的な比喩は、印象だけ残して中身を伝えないことが多いため、具体的な事実や場面で示します。

## 主語と述語をつなげる

避けたい:

```
このシステムは、複数の外部サービスと連携しながらリアルタイムで処理を行い、高い信頼性。
```

修飾語が増えると、主語に対応する述語が抜け落ちやすくなります。上の文では「このシステムは」に対する述語がありません。

望ましい:

```
このシステムは、複数の外部サービスと連携しながらリアルタイムで処理を行い、高い信頼性を保っている。
```

もうひとつのパターンとして、主語と述語がねじれる場合もあります。

避けたい:

```
受講者の多くは、対面授業のほうが集中しやすいという意見が多かった。
```

「受講者の多くは」に対して「意見が多かった」が続くと、主語と述語が対応しません。

望ましい:

```
受講者の多くは、対面授業のほうが集中しやすいと答えた。
```

もうひとつ、主語と述語の文法的な対応がずれる場合もあります。

避けたい:

```
私の将来の夢は、困っている人を助けたい。
```

望ましい:

```
私の将来の夢は、困っている人を助けることだ。
```

「夢は」に対して「助けたい」では文法的に対応しません。「夢は…ことだ」または「私は…助けたい」のどちらかに整えます。

## 主語と述語の距離を近くする

避けたい:

```
本研究は、先行研究で十分に検討されていなかった複数の変数を新たに加え、条件を統制したうえで、対面授業とオンライン授業の学習効果を比較した。
```

望ましい:

```
本研究は、対面授業とオンライン授業の学習効果を比較した。その際、先行研究で十分に検討されていなかった変数を加え、条件を統制した。
```

主語「本研究は」と述語「比較した」の間に修飾語が多く入ると、文の意味がわかりにくくなります。文を分けて距離を近づけます。

## 文をまたいで主語を統一する

避けたい:

```
担当者がこの不具合を先週発見した。この不具合は古いライブラリに起因するものだった。
```

望ましい:

```
この不具合は先週担当者によって発見された。原因は古いライブラリにあった。
```

文脈上の主語は「不具合」です。悪い例では前半の主語が「担当者」になっており、二つの文で主語が揺らいでいます。主語を統一すると、読み手が流れを追いやすくなります。

## 能動態を基本にする

避けたい:

```
新しいガイドラインが全社員に共有されたことで、業務の進め方が統一された。
```

望ましい:

```
管理部が新しいガイドラインを全社員に共有し、業務の進め方を統一した。
```

受動態は主張を弱めます。意図的に弱めたいとき以外は、動作をする人を主語にした能動態で書きます。

## 体言止めを使わない

避けたい:

```
美しく、洗練された文章。優しさの中に熱い情熱を帯びた日本語を。
```

望ましい:

```
文章は美しく、洗練されている。優しさの中に熱い情熱を帯びた日本語で書く。
```

名詞や名詞句で文を終えず、述語まで書ききります。余韻を出そうとして体言止めにすると、意味が曖昧になりがちです。

## 長い文は分ける

避けたい:

```
この調査では対面授業とオンライン授業の両方を受けた学生にアンケートを行い、学習効果と満足度の回答を集計したうえで、二つの形式の違いを多角的に分析した。
```

望ましい:

```
この調査では、対面授業とオンライン授業の両方を受けた学生にアンケートを行った。学習効果と満足度の回答を集計し、二つの形式の違いを多角的に分析した。
```

一文が長くなったら、接続詞や句の区切りで二つか三つに分けます。

特に連用形（「〜で」「〜て」）でつなぎ続けると一文がどこまでも伸びるため、意識して文を閉じます。

避けたい:

```
彼は幼いときから昆虫が大好きで、夏になると一日中森を歩き回って昆虫を集め、家に帰って取ってきた虫を図鑑で調べているうちに、くたびれ果てて虫かごをあけたまま眠り、その間に虫たちは夜の闇に飛び立っていくのだった。
```

望ましい:

```
彼は幼いときから昆虫が大好きだった。夏になると一日中森を歩き回って昆虫を集めた。家に帰って取ってきた虫を図鑑で調べるうちに、くたびれ果てて虫かごをあけたまま眠ってしまう。その間に虫たちは夜の闇に飛び立っていくのだった。
```

## 読点を適切に打つ

避けたい:

```
図書館が混んでいたので空き教室を探しやっと見つけた教室で予習した。
```

望ましい:

```
図書館が混んでいたので空き教室を探し、やっと見つけた教室で予習した。
```

読点がないと意味の区切りが見えず、「探しやっと」が一語に見えてしまいます。音読して息継ぎが要るところに読点を打ちます。

## 単純接続の「が」を使わない

避けたい:

```
会議は午前中に終わりましたが、午後から資料をまとめました。
```

望ましい:

```
会議は午前中に終わり、午後から資料をまとめた。
```

ここでの「が」は逆接ではなく、前後をただつないでいるだけです。逆接の「が」と混同しやすいため、単純接続には使いません。

## 接続詞を使いすぎない

避けたい:

```
対面授業には直接質問できる利点がある。しかし、通学に時間がかかるという課題もある。一方、オンライン授業は移動の負担が少ない。そして、録画を見返せるという利点もある。したがって、それぞれの長所を活かした運用が求められる。
```

望ましい:

```
対面授業には直接質問できる利点がある一方、通学に時間がかかる。オンライン授業は移動の負担が少なく、録画も見返せる。それぞれの長所を活かした運用が求められる。
```

なくても意味が通る接続詞は削ります。接続詞の役目は前後の関係を補助することに過ぎません。

特に逆接の接続詞が連続すると、流れが不明になります。

避けたい:

```
今日は朝から雨だった。しかし、気温が高かった。だが、電車の冷房が効きすぎて寒かった。
```

望ましい:

```
今日は朝から雨だったが気温は高かった。しかし、電車の冷房が効きすぎて寒かった。
```

逆接が続くときは、一方を文中に組み込んで接続詞の数を減らします。

## 同じ文末を繰り返さない

避けたい:

```
この手法は多くの分野で使われている。特に医療分野での応用が進んでいる。近年は教育分野でも注目されている。今後さらに普及すると考えられている。
```

望ましい:

```
この手法は多くの分野で使われている。特に医療分野での応用が進んでおり、近年は教育分野でも注目を集めた。今後さらに普及するだろう。
```

同じ語尾が三回以上続くと単調な印象になります。文末を工夫して変化をつけます。

## 文と文のつながりを意識する

避けたい:

```
レポートの構成は重要である。データの収集には時間がかかった。結論では今後の課題を述べた。
```

望ましい:

```
データの収集には時間がかかったが、十分な量を確保できた。それをもとにレポートを構成し、結論で今後の課題を述べた。
```

個々の文に問題がなくても、前後の文がつながっていないと話が飛んでいるように読めます。順序を入れ替えたり、つなぎの言葉を補ったりして、流れを整えます。

## 段落の構造

レポートや学術的な文章では、段落の先頭に中心文を置きます。

避けたい:

```
タバコを吸うと肺にニコチンやタールが蓄積する。その煙は周りの人も吸うことになり、その人の肺にもニコチンやタールが入る。したがって、タバコは健康に良くない。
```

望ましい:

```
タバコは健康に良くない。なぜなら、タバコを吸うと肺にニコチンやタールが蓄積するからだ。その煙は周りの人も吸うことになり、その人の肺にもニコチンやタールが入る。
```

段落の冒頭に結論（中心文）を置き、そのあとに根拠や説明を並べます。中心文だけを拾い読みしても論旨が追えるのが目安です。

## 推測を事実として書かない

避けたい:

```
オンライン授業の方が満足度は高い。
```

望ましい:

```
今回の調査では、オンライン授業の満足度が高い傾向が見られた。
```

## 自信過剰な断定を避ける

避けたい:

```
この手法を使えば、必ず性能に効く。
```

望ましい:

```
この手法を使うと、性能が向上する可能性がある。
```

## 曖昧な表現を避ける

避けたい:

```
オンライン授業は学習効果が高いと思う。対面授業にも利点があると言われている。
```

望ましい:

```
今回の調査では、オンライン授業の学習効果が高い傾向が見られた。対面授業には直接質問できるという利点がある。
```

「〜と思う」「〜と言われている」は根拠を示していない印象を与えます。調査や事実にもとづいて言い切るか、根拠を添えます。
