# 訳例と検証の実例

SKILL.md の手順を実際に適用した例です。出力形式（訳文、戻し訳、ニュアンスの検証、代替案）の見本としても使います。主な想定場面であるチャットの例（例1、例2）を先に、文体の切り替えが必要な改まった場面の例（例4）を後に置いています。

## 目次

- 例1: 日本語 → 台湾華語（ゲーム内チャット）

- 例3: 日本語 → 台湾華語（うっかり大陸スラングを使う失敗の例）
- 例4: 日本語 → 台湾華語（改まった場面への切り替え: ビジネスの断り）
- 例5: 台湾華語 → 日本語（友人への予定変更の連絡）
- 例6: 台湾華語 → 日本語（MMO の募集チャット）

## 例1: 日本語 → 台湾華語（ゲーム内チャット）

原文:

```
ごめん、さっきめっちゃラグくてまじで何もできなかったw
次のマッチは本気出すわ
```

訳文:

```
抱歉，剛剛有夠lag害我什麼都不能動XD
下一場我認真打啦
```

戻し訳:

```
ごめん、さっきすごくラグくて全然動けなかったXD
次の試合は本気でやるからね
```

ニュアンスの検証:

- 「ラグい」は台湾でも英語のまま lag と書くのが自然。延遲很高 と訳すと説明的になりすぎて、チャットの温度が変わってしまう。
- 文末の「w」は笑いの記号なので XD で対応させた。笑死 でもよいが、ここは自嘲の軽い笑いなので XD のほうが近い。
- 「本気出すわ」の「わ」の軽い調子を、文末の 啦 で再現した。認真打 だけだと決意表明のように硬くなる。
- 害我（〜のせいで私は）を入れることで、「ラグのせいで」という原文の言い訳のニュアンスを保った。

代替案:

- もっとおどけた調子にするなら 下一場看我的啦（次は俺に任せろって）。原文より一歩踏み込んだ言い方になるため、相手との距離感で選ぶ。

## 例2: 台湾華語 → 日本語（Discord での雑談）

原文:

```
剛剛那場超好笑 我們兩個都卡在門口出不去XD
沒差啦 玩得開心就好 明天要不要再繼續？
```

訳文:

```
さっきの試合まじで笑った、二人して入口に引っかかって出られなくなってたしXD
まあ楽しかったからいいでしょ。続きは明日やる？
```

戻し訳:

```
剛剛那場真的超好笑 我們兩個一起卡在門口出不來XD
不過玩得很開心啦 明天再繼續嗎？
```

ニュアンスの検証:

- 超好笑 は「まじで笑った」と、笑いの温度をそのまま日本語のチャット口調にした。「とても面白かった」では硬い。
- 卡在門口 の 卡 は「引っかかる、スタックする」。ゲームの文脈なので「引っかかって出られなくなってた」が自然。
- 沒差啦 は台湾でよく使う「別にいい、気にしない」（大陸では 无所谓 が普通）。ここでは直後の 玩得開心就好 とあわせて「まあ楽しかったからいいでしょ」とまとめた。戻し訳で 沒差 のニュアンスが 不過…啦 に弱まっていることを確認し、投げやりではなく満足している含みが保たれているので許容とした。
- 要不要 の誘いは「やる？」で対応する。「やりますか？」だと距離が出る。

## 例3: 日本語 → 台湾華語（うっかり大陸スラングを使う失敗の例）

原文:

```
今のプレイやばすぎ！神！
```

避けたい訳（大陸のネットスラング）:

```
刚才的操作太牛逼了！666！
```

台湾華語の訳:

```
剛剛那波也太神了吧！超猛！
```

牛逼 と 666 は大陸のスラングで、台湾の相手に使うと出自がすぐに分かります。台湾では 太神啦/超猛/好猛 が同じ場面の定番です。那波（今のあの場面）もゲームチャットらしい言い方です。

## 例4: 日本語 → 台湾華語（改まった場面への切り替え: ビジネスの断り）

原文:

```
先日はありがとうございました。例の件、社内で検討した結果、
今回は見送らせていただくことになりました。
またの機会にぜひよろしくお願いいたします。
```

訳文:

```
前陣子非常感謝您。關於先前提到的那件事，我們內部評估之後，
決定這次先不進行。期待未來還有機會合作，再麻煩您了。
```

戻し訳:

```
先日は誠にありがとうございました。以前お話しした例の件ですが、
社内で評価した結果、今回はいったん進めないことにいたしました。
今後また協力の機会があることを期待しています。その際はよろしくお願いします。
```

ニュアンスの検証:

- 検討 を 評估 と訳した。字面どおり 檢討 とすると「過ちを反省した」という意味になり、まったく違う内容が伝わってしまう。
- 見送らせていただく を 先不進行 とした。先（ひとまず）を入れることで、完全な拒絶ではなく今回は見合わせるという日本語の婉曲さを保っている。戻し訳の「いったん進めない」がこの含みを保持できていることを確認した。
- またの機会にぜひよろしくお願いいたします は決まり文句で、直訳すると中国語では意味をなさない。断りの締めとしての機能（関係を切らない意思表示）を 期待未來還有機會合作 で果たし、再麻煩您了 で丁寧さを添えた。

代替案:

- 決定這次先不進行 をより硬くするなら 決定這次暫緩辦理。公文書調になるため、相手との距離感で選ぶ。

## 例5: 台湾華語 → 日本語（友人への予定変更の連絡）

原文:

```
不好意思，我明天有事沒辦法過去，可以改約下禮拜嗎？真的很抱歉耶！
```

訳文:

```
ごめん、明日は用事ができて行けなくなっちゃった。来週に変更してもらえるかな？
本当にごめんね！
```

戻し訳:

```
抱歉，我明天有事沒辦法過去了。可以改到下週嗎？真的很對不起喔！
```

ニュアンスの検証:

- 下禮拜 は台湾でよく使う言い方で 下週 と同じ意味。日本語は単に「来週」でよい。
- 文末の 耶 は親しみと軽い感情の高ぶりを表す台湾らしい語尾で、フォーマルな謝罪ではないことを示している。日本語側を「誠に申し訳ございません」と訳すと温度が合わないため、「ごめんね！」で対応させた。戻し訳でも同じ温度の 喔 が現れることを確認した。
- 我有事 の 有事 は「用事がある」。原文全体がくだけた口調（不好意思、耶）なので、日本語も常体のくだけた文体で統一した。

代替案:

- 相手が友人ではなく仕事の相手なら、同じ原文でも「すみません、明日は都合がつかなくなってしまいました。来週に変更していただけますか。本当に申し訳ありません」と敬体に訳す。原文の文体だけでなく、二人の関係から丁寧さの度合いを決める。

## 例6: 台湾華語 → 日本語（MMO の募集チャット）

原文:

```
晚上八點出團打王 目前缺一補 要來的+1或密我
打完順便刷一下週常
```

訳文:

```
夜8時からボスレイド行くよー あとヒーラー1枠
来れる人は+1かウィスちょうだい
終わったらついでにウィークリーも回す予定
```

戻し訳:

```
晚上八點要打王團 還缺一個補
可以來的人+1或密我
打完之後順便刷週常
```

ニュアンスの検証:

- 出團打王 はレイドでボスを討伐しに行くこと。「ボスレイド行く」で MMO プレイヤーに通じる言い方にした。
- 缺一補 の 補 は補師（ヒーラー）の略。「ヒーラー1枠」と募集らしい言い方にした。
- +1 は募集への参加表明の定型で、日本のゲームチャットでも +1 はそのまま通じるため残した。密我 は「ウィスパーして」なので、MMO で自然な「ウィスちょうだい」にした。DM が普通のゲームなら「DMちょうだい」でもよい。
- 刷週常 の 刷 は周回すること、週常 はウィークリークエスト。「ウィークリーを回す」が対応する言い方になる。
- 募集告知なので、訳文も日本の募集チャットで実際に流れる形（体言止めや「〜予定」）に寄せ、完全な文に整えすぎないようにした。
