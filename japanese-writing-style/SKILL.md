# 文章スタイル

このスキルは、日本語の文章を作成・添削・編集するときに従う基準をまとめたものです。レポート、学術課題、その他の文書を書くとき、または直すときに使います。具体的な添削例は [references/examples.md](references/examples.md) にまとめています。

## 適用対象

- 人が読む日本語の散文に適用する。レポート、学術課題、記事、説明文、解説などが対象になる。
- 引用した他人の文章は、引用元の表記を変えない。このスキルの基準は、自分が書く地の文にだけ及ぶ。

## 記号と書式

- 太字記法を使わない。出力に `**` を含めない。強調したい内容は、語順や言い回しで示す。
- 原則として `"` や `「` `」` を使わない。人間が書く自然な文章にはあまり出てこない。固有名詞の区別や引用、コードなど、本当に必要な場面に限る。
- 並列の区切りには `・`（中黒）よりも、`/` や読点を使う。
- 番号を本文や見出しに手で振らない。後の編集で順序や項目数が変わると、手で振った番号が崩れるため。
  - 本文の段落に `1.` `2.` と数字を書かない。
  - 見出しに `## 1.` `### 1.1` のような通し番号を付けない。
  - 列挙するときは標準のリスト記法を使う。順序そのものに意味がない限り、番号なしリストにする。順序付きが必要な場合も、ソースに通し番号を手書きせず、Markdown の記法に任せる。

番号を手で振った、避けたい書き方:

```
1. 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
   そして受講者の満足度から見た評価までを順に検討する。
2. 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

標準のリスト記法を使った、望ましい書き方:

```
- 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
  そして受講者の満足度から見た評価までを順に検討する。
- 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

見出しに番号を付けた、避けたい書き方:

```
## 1. 課題1：対面授業とオンライン授業の比較

### 1.1 学習効果の違い
```

- 横書きの英数字は半角で書く。全角の英数字を使わない。

## 言葉づかい

- 助詞（てにをは）を省略しない。「〜について検討する」を「〜検討する」のように縮めない。
- 単語を不自然に圧縮しない。「特定のタスクで」を「特定タスク用」のように縮めない。文章を短くしたいときは、単語を削るのではなく、全体の要点を絞る。
- 平易で丁寧な日本語で書く。日常的に使わない言葉や、英語を直訳したような言い回しを避ける。過剰な前置きや、決まり文句の多用を避ける。
- 誇張や過剰な修飾を避け、標準的な言葉を使う。
- 「手触り」「解像度」「〜の本質」のような抽象的な比喩で、具体的な内容をぼかさない。実際の事実や場面で示す。
- 「Xつの観点から」「AではなくB」のような決まり文句のパターンを繰り返さない。
- 主語と述語のつながりを意識する。一文ごとに、主語（だれが/何が）と述語（どうする/どうした）が正しく対応しているかを確認する。修飾語が増えて文が長くなると、主述の対応が崩れやすい。
- 文をまたいで主語がぶれないようにする。文脈上の主語と文法上の主語を一致させる。主語が揺らぐと、文同士のつながりが見えにくくなる。
- 能動態を基本にする。受動態や名詞化は主張を弱めるため、意図的に弱めたいとき以外は能動態で書く。
- 主語と述語の距離を近くする。間に修飾語が多く入ると意味がわかりにくくなるため、距離が遠い場合は文を分ける。
- 体言止めを使わない。「美しく、洗練された文章。」のように名詞や名詞句で文を終えず、述語まで書ききる。
- ひらける漢字はひらく。漢字が続くと読みづらくなるため、意味の伝わりに支障がなければひらがなにする。たとえば「事」→「こと」、「成る」→「なる」、「其れ」→「それ」、「云える」→「いえる」のように書く。
- い抜き言葉、ら抜き言葉を使わない。「〜している」を「〜してる」のように「い」を抜いたり、「見られる」を「見れる」のように「ら」を抜いたりしない。
- 口語（話し言葉）を使わない。標準的な書き言葉で書く。「なので」は「したがって」や「そのため」に、「いっぱい」は「たくさん」に、「月一で」は「月に一度」のように直す。
- だ/である体で文体を統一する。です/ます体を途中で混ぜない。

## 内容の扱い

- 推測や根拠の弱い内容を、事実として書かない。推測を書くときは、事実と区別して明示する。短い推測はその場で区別し、長い推測は本文と分けて示す。
- 確実なことと不明なことを分けて示す。曖昧な点は断定せず、不確実だと記す。
- 知らないことは知らないと書く。知ったかぶりや、推測を事実のように述べることを避ける。
- 文章を添削するときは、安易に肯定しない。問題点や弱い前提を隠さずに指摘する。
- 自信過剰な表現を避ける。不確実なことを断定せず、例外や余地を残す。たとえば「効きます」ではなく「効くとされる」「効く可能性が高い」のように書く。ただし、確立した事実まで曖昧にぼかさない。検証なしの称賛（「鋭い視点です」など）もしない。
- 「〜と思う」「〜と考える」「〜と言われている」を安易に使わない。根拠を示して言い切るか、根拠が不足しているなら調査を補う。曖昧な表現の多用は、調査が不十分だという印象を読み手に与える。

## 構成

- レポートや学術的な文章では、段落の先頭に中心文（その段落で最も伝えたいこと）を置き、そのあとに説明や根拠、事例を並べる。中心文だけを拾い読みしても論旨が追えるようにする。
- 要点が複数あるときは、まず短い箇条書きで一覧を示し、そのあと各項目を段落で詳しく説明する。箇条書きは要約として短く書く。説明は短い文を並べず、文をつなげて段落にする。
- 論点が一つだけのとき、または短い回答で済むときは、箇条書きを使わなくてよい。
- 見出しは内容を端的に示す。「〜が教えてくれること」「〜という挑戦」のような装飾的な見出しを付けない。

## 文のリズム

- 一文が長くなったら二つか三つに分ける。接続詞の前が区切りの目安になる。
- 読点は多すぎても少なすぎても読みにくくなる。読点がないと意味の区切りが見えず、多すぎると流れが途切れる。迷ったら音読して確かめる。
- 接続詞は正しく使い、最小限にとどめる。
  - 単純接続の「が」を使わない。「会議は午前中に終わりましたが、午後から資料をまとめました」のように逆接ではない「が」は、逆接と紛らわしいため避ける。
  - なくても意味が通る接続詞は削る。接続詞が続くと文の流れが途切れる。
- 同じ文末を三回以上繰り返さない。「〜です。〜です。〜です。」のように同じ語尾が続くと単調になる。
- 文と文のつながりを意識する。前の文と次の文の関係がはっきりしないと、話があちこちに飛んでいるように読める。

## ルールの優先順位

ルールが互いに衝突したときは、次の順で判断する。

- 意味の正確さを最優先する。体裁を整えるために、事実や元の意味を変えない。
- ユーザーの明示的な指示は、このスキルの細則より優先する。指定された表記や用語があれば、それに従う。
- 引用やコードなど、原文の保持がいる部分は、体裁より保持を優先する。
- 既存の文書を直すときは、その文書で一貫している表記やトーンを尊重する。全体の統一を壊してまで細則を当てはめない。

## 添削するときの態度

新規に書くときは、ここまでの基準をそのまま適用する。既存の文章を直すときは、介入を最小限にする。

- 基準に反する箇所を直し、それ以外は元の言い回しや筆者の意図を残す。全面的には書き換えない。
- 必ず直すべき点と、提案にとどめる点を分けて示す。
- 直したあとで、意味が変わっていないかを確認する。
