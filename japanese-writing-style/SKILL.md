# 文章スタイル

読み手にとっての読みやすさを最優先する。結論を先に置き、読み手と場面に合わせて書く。以下の基準は、そのための手立てである。

基準ごとの避けたい書き方と望ましい書き方の対比は [references/examples.md](references/examples.md) にまとめている。文章の作成または添削を始める前に、冒頭の目次から該当する節を読む。

## 適用対象と適用範囲

- 人が読む日本語の散文に適用する。レポート、学術課題、記事、説明文、解説などが当たる。
- 引用した他人の文章には適用しない。引用元の表記を変えず、基準は自分が書く地の文にだけ及ぶ。
- コードとコミットメッセージには適用しない。体言止めや語の省略が慣習として使われるためだ。
- 依頼された範囲のすべてに適用する。複数の節や複数の文書があっても、最初のひとつで止めない。
- 各基準に挙げる語や表現は代表例なので、同種の表現すべてに適用する。

## 記号と書式

- 太字記法を使わない。出力に `**` を含めない。強調したい内容は、語順や言い回しで示す。
- 原則として `"` や `「` `」` を使わない。強調目的で多用すると文が途切れて読みにくくなる。固有名詞の区別、引用、コード、語形や用語をそのまま示すメタ言及（用語の初出や言い回しへの言及）に限って使う。
- 並列の区切りには `・`（中黒）よりも、`/` や読点を使う。
- 横書きの英数字は半角で書く。全角の英数字を使わない。
- 番号を本文や見出しに手で振らない。後の編集で順序や項目数が変わると、手で振った番号が崩れるためだ。
  - 本文の段落に `1.` `2.` と数字を書かない。
  - 見出しに `## 1.` `### 1.1` のような通し番号を付けない。
  - 列挙するときは標準のリスト記法を使う。順序そのものに意味がない限り、番号なしリストにする。順序付きが必要な場合も、ソースに通し番号を手書きせず、Markdown の記法に任せる。

番号を手で振った、避けたい書き方:

```
1. 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
   そして受講者の満足度から見た評価までを順に検討する。
2. 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

標準のリスト記法を使った、望ましい書き方:

```
- 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
  そして受講者の満足度から見た評価までを順に検討する。
- 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

見出しに番号を付けた、避けたい書き方:

```
## 1. 課題1：対面授業とオンライン授業の比較

### 1.1 学習効果の違い
```

## 言葉づかい

- 助詞（てにをは）を省略しない。「〜について検討する」を「〜検討する」のように縮めない。
- 単語を不自然に圧縮しない。「特定のタスクで」を「特定タスク用」のように縮めない。文章を短くしたいときは、単語を削るのではなく、全体の要点を絞る。
- 平易で丁寧な日本語で書く。日常的に使わない言葉や、英語を直訳したような言い回しを避ける。過剰な前置きや、決まり文句の多用を避ける。
- 誇張や過剰な修飾を避け、標準的な言葉を使う。
- 「手触り」「解像度」「〜の本質」のような抽象的な比喩で、具体的な内容をぼかさない。実際の事実や場面で示す。
- 「Xつの観点から」「AではなくB」のような決まり文句のパターンを繰り返さない。
- 主語と述語のつながりを意識する。一文ごとに、主語（だれが/何が）と述語（どうする/どうした）が正しく対応しているかを確認する。修飾語が増えて文が長くなると、主述の対応が崩れやすい。
- 文をまたいで主語がぶれないようにする。文脈上の主語と文法上の主語を一致させる。主語が揺らぐと、文同士のつながりが見えにくくなる。
- 指示語の参照を明確にする。「これ」「それ」「その〜」が何を指すか、前の文から一意にたどれないときは、指示語を使わず名詞を繰り返す。
- 能動態を基本にする。受動態や名詞化は主張を弱めるため、意図的に弱めたいとき以外は能動態で書く。ただし、文をまたいで主題をそろえるためなら受動態を選んでよい。動作主に焦点があるなら能動態、主題の連続を優先するなら受動態、と使い分ける。添削で動作主を補うときは、原文や文脈から動作主が確実に分かる場合に限る。
- 主語と述語の距離を近くする。間に修飾語が多く入ると意味がわかりにくくなるため、距離が遠い場合は文を分ける。
- 修飾語のかかり先を明確にする。「AとBのC」のように修飾の範囲が複数に取れる並びを避け、かかり先が一意にならないときは語を補う。
- 体言止めを使わない。「美しく、洗練された文章。」のように名詞や名詞句で文を終えず、述語まで書ききる。
- ひらける漢字はひらく。漢字が続くと読みづらくなるため、意味の伝わりに支障がなければひらがなにする。たとえば「事」→「こと」、「成る」→「なる」、「其れ」→「それ」、「云える」→「いえる」のように書く。
- い抜き言葉、ら抜き言葉を使わない。「〜している」を「〜してる」のように「い」を抜いたり、「見られる」を「見れる」のように「ら」を抜いたりしない。
- 口語（話し言葉）を使わない。標準的な書き言葉で書く。「なので」は「したがって」や「そのため」に、「いっぱい」は「たくさん」に、「月一で」は「月に一度」に直す。
- 冗長な言い回しを避ける。「することができる」は「できる」に、「〜を行う」は動詞そのものにする。たとえば「分析を行う」は「分析する」と書く。
- 二重否定を避ける。「〜ないわけではない」「〜できなくはない」のような形は回りくどい。弱めた肯定を伝えたいときは、二重否定ではなく条件や程度を具体的に示す。
- 「という」「〜的」を多用しない。なくても意味が通るなら削る。
- 「の」の連続を避ける。一文に「の」が三つ以上続くと名詞同士の関係を追いにくくなる。動詞句に置き換えたり、句を分けたりして減らす。
- 「非常に」「極めて」のような強意語を重ねない。程度を伝えたいときは、理由や数値で示す。
- 文体を統一する。です/ます体とだ/である体を途中で混ぜない。新規に書くときはだ/である体を既定にする。既存の文書を直すときは、その文書で優勢な文体に合わせて統一する。
- 時制を統一する。過去の記述と現在形を無意識に混ぜない。時制を変えるのは、時間軸を変える意図があるときに限る。
- 用語と表記を統一する。同じ対象には同じ語、同じ表記を使う。表記ゆれがあると、読み手が別の対象かと疑う。既存の文書を直すときは、その文書で優勢な表記に合わせる。

## 内容の扱い

- 断定形で書いた文ごとに、根拠が文書内に示されているか、一般に確立した事実であるかを確認する。どちらにもあてはまらない文は断定をやめ、未確認であると明記する。確立した事実にまで根拠の併記は求めない。
- 推測は、短ければその場で事実と区別し、長ければ本文と分けて示す。
- 主張の強さを根拠の強さに合わせる。根拠はあるが確度が低い内容は断定せず、「効きます」ではなく「効く可能性が高い」のように程度を示す。ただし、確立した事実まで曖昧にぼかさない。
- 「〜と思う」「〜と考える」「〜と言われている」を安易に使わない。根拠を示して言い切るか、根拠が不足しているなら調査を補う。曖昧な表現の多用は、調査が不十分だという印象を読み手に与える。
- 検証なしの称賛（「鋭い視点です」など）や安易な肯定をしない。文章を添削するときは、問題点や弱い前提を隠さずに指摘する。

## 構成

- 段落の先頭に中心文（その段落で最も伝えたいこと）を置き、そのあとに説明や根拠、事例を並べる。中心文だけを拾い読みしても論旨が追えるようにする。
- 一つの段落では一つの話題を扱う。話題が変わるところで段落を分ける。
- 要点が複数あるときは、まず短い箇条書きで一覧を示し、そのあと各項目を段落で詳しく説明する。箇条書きは要約として短く書く。説明は短い文を並べず、文をつなげて段落にする。
- 箇条書きの項目は構文をそろえる。名詞句で書くか、同じ終わり方の文で書くか、いずれかに統一する。
- 論点が一つだけのとき、または短い回答で済むときは、箇条書きを使わなくてよい。
- 見出しは内容を端的に示す。「〜が教えてくれること」「〜という挑戦」のような装飾的な見出しを付けない。

## 文のリズム

- 一文が長くなったら二つか三つに分ける。接続詞の前が区切りの目安になる。
- 読点は多すぎても少なすぎても読みにくくなる。読点がないと意味の区切りが見えず、多すぎると流れが途切れる。迷ったら音読して確かめる。
- 接続詞は正しく使い、最小限にとどめる。
  - 単純接続の「が」を使わない。「会議は午前中に終わりましたが、午後から資料をまとめました」のように逆接ではない「が」は、逆接と紛らわしいため避ける。
  - なくても意味が通る接続詞は削る。接続詞が続くと文の流れが途切れる。
- 同じ文末を三回以上繰り返さない。「〜です。〜です。〜です。」のように同じ語尾が続くと単調になる。
- 文と文のつながりを意識する。前の文と次の文の関係がはっきりしないと、話があちこちに飛んでいるように読める。

## ルールの優先順位

ルールが互いに衝突したときは、次の順で判断する。

- 意味の正確さを最優先する。体裁を整えるために、事実や元の意味を変えない。
- ユーザーの明示的な指示は、このスキルの細則より優先する。指定された表記や用語があれば、それに従う。
- 読みやすさと細則が衝突したら、読みやすさを優先する。ただし、どこがどう読みにくいかを言えるときに限る。

## 添削の手順と出力

新規に書くときは基準をそのまま適用する。既存の文章を直すときは、次の手順で進める。

- 基準に反する箇所だけを直し、全面的には書き換えない。元の言い回しや筆者の意図、その文書で一貫している表記やトーンは、細則を当てはめてまで崩さない。
- 直したあとで、修正前後の意味が変わっていないかを見比べる。変わっていたら修正し直す。

添削の出力には、次を含める。

- 添削後の本文。修正が文書のごく一部にとどまる場合は、修正した箇所とその前後だけを示してもよい。
- 必ず直すべき点の一覧。どの基準に反していたかを短く添える。
- 提案にとどめる点の一覧。基準違反ではない改善案は、ここに分けて示す。該当がなければ省略してよい。
