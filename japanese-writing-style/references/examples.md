# 添削例

SKILL.md の各基準について、避けたい書き方と望ましい書き方を対にして示します。基準そのものは SKILL.md にあり、このファイルはその適用例をまとめた補足です。

## 目次

本文の節は、この目次の順に並んでいます。

- 記号と書式: 太字をやめる / かぎ括弧と引用符を減らす / 中黒より読点や区切りを使う / 番号を手で振らない / 装飾的な見出しを避ける
- 言葉づかい: 誇張や過剰な修飾を避ける / 過剰な前置きを避ける / 助詞を省略しない / 単語を不自然に圧縮しない / 「の」の連続を避ける / 口語と、い抜き、ら抜きを場面で判断する / 冗長な言い回しを避ける / 二重否定を避ける / 強意語に頼らない / 文体を統一する / 時制を統一する / 用語と表記を統一する / ひらける漢字はひらく / 決まり文句のパターンを繰り返さない / 抽象的な比喩語に頼らない
- 文の構造: 主語と述語をつなげる / 主語と述語の距離を近くする / 修飾語のかかり先を明確にする / 文をまたいで主語を統一する / 指示語の参照を明確にする / 能動態を基本にする / 体言止めを使わない / 長い文は分ける / 埋もれた列挙を箇条書きに開く / 読点を適切に打つ
- 文と文の流れ: 単純接続の「が」を使わない / 接続詞を使いすぎない / 同じ文末を繰り返さない / 文と文のつながりを意識する

## 太字をやめる

避けたい:

```
**結論**: オンライン授業は移動の負担を減らす。
```

望ましい:

```
結論として、オンライン授業は移動の負担を減らす。
```

## かぎ括弧と引用符を減らす

避けたい:

```
"対面授業" には「その場で質問できる」という利点がある
```

望ましい:

```
対面授業には、その場で質問できるという利点がある。
```

## 中黒より読点や区切りを使う

避けたい:

```
評価軸は学習効果・運営コスト・満足度の三つである。
```

望ましい:

```
評価軸は、学習効果と運営コスト、満足度の三つである。
```

## 番号を手で振らない

避けたい:

```
## 1. 比較の観点
### 1.1 学習効果
### 1.2 運営コスト
```

望ましい:

```
## 比較の観点
### 学習効果
### 運営コスト
```

本文の段落でも同様です。

避けたい:

```
1. 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
   そして受講者の満足度から見た評価までを順に検討する。
2. 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

望ましい:

```
- 対面授業とオンライン授業について、学習効果の違いから運営コストの違い、
  そして受講者の満足度から見た評価までを順に検討する。
- 形式は違うのに、ある観点では同じ成果が得られ、別の観点では差が出る、
```

## 装飾的な見出しを避ける

避けたい:

```
## 対面授業が私たちに教えてくれること
```

望ましい:

```
## 対面授業の利点
```

## 誇張や過剰な修飾を避ける

避けたい:

```
この画期的な手法は、あらゆる場面で圧倒的な効果を発揮する。
```

望ましい:

```
この手法は、画像分類の精度を従来の手法より高めた。
```

中身を示さない動詞にも同じことが当てはまります。

避けたい:

```
この章ではエラーハンドリングについて深掘りします。
```

望ましい:

```
この章ではエラーハンドリングを説明します。
```

本文に中身が書かれているなら、「エラーの分類と、分類ごとの再送可否を説明します」のように具体化します。中身がなければ、普通の動詞への置き換えにとどめ、原文にない内容を補いません。

## 過剰な前置きを避ける

避けたい:

```
ご存知のように、現代社会において情報技術の重要性はますます高まっているが、本稿ではオンライン授業について論じる。
```

望ましい:

```
本稿ではオンライン授業について論じる。
```

## 助詞を省略しない

避けたい:

```
本稿は対面とオンライン比較し、満足度評価する。
```

望ましい:

```
本稿では対面とオンラインを比較し、満足度を評価する。
```

## 単語を不自然に圧縮しない

避けたい:

```
特定タスク用の最適化を施す。
```

望ましい:

```
特定のタスクに向けた最適化を施す。
```

## 「の」の連続を避ける

避けたい:

```
会議の資料の印刷の部数を確認する。
```

望ましい:

```
会議の資料を印刷する部数を確認する。
```

## 口語と、い抜き、ら抜きを場面で判断する

改まった文書では、書き言葉にそろえます。

避けたい:

```
データは増えてるが、原因はまだ見れてない。なので、いっぱい必要だ。
```

望ましい:

```
データは増えているが、原因はまだ見られていない。したがって、たくさん必要だ。
```

会話や砕けた文書では、自然さを優先して残してかまいません。

```
データは増えてるんですが、原因はまだ見れてないです。
```

改まった文書で言い換えるときの、よくある例:

- なので → したがって、そのため
- いっぱい → たくさん、多く
- やっぱり → やはり
- ちゃんと → きちんと、正しく
- 〜みたいな → 〜のような

## 冗長な言い回しを避ける

避けたい:

```
本システムでは、データの分析を行うことができる。
```

望ましい:

```
本システムはデータを分析できる。
```

## 二重否定を避ける

避けたい:

```
この計画は実現できないわけではない。
```

望ましい:

```
この計画は、条件がそろえば実現できる。
```

## 強意語に頼らない

避けたい:

```
この結果は非常に重要だという評価が一般的である。
```

望ましい:

```
この結果は、後続の研究の前提を変えるため重要である。
```

## 文体を統一する

避けたい:

```
公園に行きましたが、休日でしたので、人がたくさんいました。しかし、静かな場所もあった。
```

望ましい:

```
公園に行ったが、休日だったので、人がたくさんいた。しかし、静かな場所もあった。
```

## 時制を統一する

避けたい:

```
調査は三月に行う。集計の結果、傾向が見られた。
```

望ましい:

```
調査は三月に行った。集計の結果、傾向が見られた。
```

## 用語と表記を統一する

避けたい:

```
サーバーを構築する。サーバの設定を変えると、server の負荷が下がる。
```

望ましい:

```
サーバーを構築する。サーバーの設定を変えると、サーバーの負荷が下がる。
```

## ひらける漢字はひらく

避けたい:

```
其の事が原因と成り、更に状況が悪化した事は否めない。
```

望ましい:

```
そのことが原因となり、さらに状況が悪化したことは否めない。
```

よくある例:

- 事 → こと
- 成る → なる
- 其の → その
- 更に → さらに
- 出来る → できる
- 全て → すべて
- 但し → ただし
- 予め → あらかじめ

## 決まり文句のパターンを繰り返さない

避けたい:

```
この問題を3つの観点から整理する。
第一に、コストの観点から見ると……
第二に、品質の観点から見ると……
第三に、速度の観点から見ると……
```

望ましい:

```
コストが一番大きな問題で、そのうえ品質にも影響が出ている。速度はいまのところ許容範囲にある。
```

決まり文句は、一度使うぶんには問題ありませんが、繰り返すと文章全体が型にはまった印象になります。上の例では、コストと品質と速度に重みの差があるのに、同じ形で並べたために差が消えています。

## 抽象的な比喩語に頼らない

避けたい:

```
オンライン授業の本質は、学習体験の解像度を変える点にある。教室にはない手触りがそこにある。
```

望ましい:

```
オンライン授業の特徴は、録画を後から見直せたり、チャットで質問できたりする点にある。教室での対面とは進め方が違ってくる。
```

## 主語と述語をつなげる

避けたい:

```
このシステムは、複数の外部サービスと連携しながらリアルタイムで処理を行い、高い信頼性。
```

上の文では「このシステムは」に対する述語がありません。

望ましい:

```
このシステムは、複数の外部サービスと連携しながらリアルタイムで処理し、高い信頼性を保っている。
```

次は、主語と述語がねじれる例です。

避けたい:

```
受講者の多くは、対面授業のほうが集中しやすいという意見が多かった。
```

「受講者の多くは」に対して「意見が多かった」が続くと、主語と述語が対応しません。

望ましい:

```
受講者の多くは、対面授業のほうが集中しやすいと答えた。
```

次は、文法的な対応がずれる例です。

避けたい:

```
私の将来の夢は、困っている人を助けたい。
```

望ましい:

```
私の将来の夢は、困っている人を助けることだ。
```

「夢は」に対して「助けたい」では文法的に対応しません。「夢は…ことだ」または「私は…助けたい」のどちらかに整えます。

## 主語と述語の距離を近くする

避けたい:

```
本研究は、先行研究で十分に検討されていなかった複数の変数を新たに加え、条件を統制したうえで、対面授業とオンライン授業の学習効果を比較した。
```

望ましい:

```
本研究は、対面授業とオンライン授業の学習効果を比較した。その際、先行研究で十分に検討されていなかった変数を加え、条件を統制した。
```

上の例では、主語「本研究は」と述語「比較した」の間に修飾語が多く入っています。

## 修飾語のかかり先を明確にする

避けたい:

```
新入社員と中途採用の研修を行う。
```

望ましい:

```
新入社員の研修と中途採用の研修を行う。
```

上の例では、新入社員と中途採用者の両方に向けた研修なのか、新入社員に関する何かと中途採用の研修なのかが分かりません。

## 文をまたいで主語を統一する

避けたい:

```
担当者がこの不具合を先週発見した。この不具合は古いライブラリに起因するものだった。
```

望ましい:

```
この不具合は先週担当者によって発見された。原因は古いライブラリにあった。
```

文脈上の主語は「不具合」です。避けたい例では前半の主語が「担当者」になっており、二つの文で主語が揺らいでいます。

## 指示語の参照を明確にする

避けたい:

```
この手法は従来より精度が高い。これは今後の研究に影響する。
```

望ましい:

```
この手法は従来より精度が高い。この精度向上は今後の研究に影響する。
```

上の例の「これ」は、手法を指すのか、精度が高いことを指すのかが曖昧です。

## 能動態を基本にする

避けたい:

```
管理部によって新しいガイドラインが全社員に共有され、業務の進め方が統一された。
```

望ましい:

```
管理部が新しいガイドラインを全社員に共有し、業務の進め方を統一した。
```

添削で動作主を勝手に補ってはいけません。次の文には動作主が書かれていません。

```
新しいガイドラインが全社員に共有されたことで、業務の進め方が統一された。
```

共有したのが誰かは原文からたどれないため、この文は受動態のままにします。能動態に直すには動作主が要りますが、補えば原文にない情報が入ります。

## 体言止めを使わない

避けたい:

```
美しく、洗練された文章。優しさの中に熱い情熱を帯びた日本語を。
```

望ましい:

```
文章は美しく、洗練されている。優しさの中に熱い情熱を帯びた日本語で書く。
```

余韻を出そうとして体言止めにすると、意味が曖昧になりがちです。

## 長い文は分ける

避けたい:

```
この調査では対面授業とオンライン授業の両方を受けた学生にアンケートを行い、学習効果と満足度の回答を集計したうえで、二つの形式の違いを多角的に分析した。
```

望ましい:

```
この調査では、対面授業とオンライン授業の両方を受けた学生にアンケートを行った。学習効果と満足度の回答を集計し、二つの形式の違いを多角的に分析した。
```

次は、連用形でつなぎ続けた例です。

避けたい:

```
彼は幼いときから昆虫が大好きで、夏になると一日中森を歩き回って昆虫を集め、家に帰って取ってきた虫を図鑑で調べているうちに、くたびれ果てて虫かごをあけたまま眠り、その間に虫たちは夜の闇に飛び立っていくのだった。
```

望ましい:

```
彼は幼いときから昆虫が大好きだった。夏になると一日中森を歩き回って昆虫を集めた。家に帰って取ってきた虫を図鑑で調べるうちに、くたびれ果てて虫かごをあけたまま眠ってしまう。その間に虫たちは夜の闇に飛び立っていくのだった。
```

## 埋もれた列挙を箇条書きに開く

避けたい:

```
本調査では、受講者へのアンケート、担当教員への聞き取り、出席記録の集計、成績データの分析を経て、二つの形式を比較した。
```

望ましい:

```
本調査では、次を経て二つの形式を比較した。

- 受講者へのアンケート
- 担当教員への聞き取り
- 出席記録の集計
- 成績データの分析
```

同格の項目が三つ以上一文に埋もれていると、読み手が並列関係を組み立て直すことになります。項目が二つのときや、一文が短いときは開きません。開くのは体裁の変更なので、項目の数、順序、情報量は変えません。

## 読点を適切に打つ

避けたい:

```
図書館が混んでいたので空き教室を探しやっと見つけた教室で予習した。
```

望ましい:

```
図書館が混んでいたので空き教室を探し、やっと見つけた教室で予習した。
```

読点がないため、「探しやっと」が一語に見えてしまいます。

## 単純接続の「が」を使わない

避けたい:

```
会議は午前中に終わりましたが、午後から資料をまとめました。
```

望ましい:

```
会議は午前中に終わり、午後から資料をまとめた。
```

ここでの「が」は逆接ではなく、前後をただつないでいるだけです。

## 接続詞を使いすぎない

避けたい:

```
対面授業には直接質問できる利点がある。しかし、通学に時間がかかるという課題もある。一方、オンライン授業は移動の負担が少ない。そして、録画を見返せるという利点もある。したがって、それぞれの長所を活かした運用が求められる。
```

望ましい:

```
対面授業には直接質問できる利点がある一方、通学に時間がかかる。オンライン授業は移動の負担が少なく、録画も見返せる。それぞれの長所を活かした運用が求められる。
```

接続詞の役目は、前後の関係を補助することに過ぎません。

次は、逆接が連続する例です。

避けたい:

```
今日は朝から雨だった。しかし、気温が高かった。だが、電車の冷房が効きすぎて寒かった。
```

望ましい:

```
今日は朝から雨だったが気温は高かった。しかし、電車の冷房が効きすぎて寒かった。
```

## 同じ文末を繰り返さない

避けたい:

```
この手法は多くの分野で使われている。特に医療分野での応用が進んでいる。近年は教育分野でも注目されている。今後さらに普及すると考えられている。
```

望ましい:

```
この手法は多くの分野で使われており、特に医療分野で応用が進んでいる。近年は教育分野でも注目されており、今後さらに普及すると考えられている。
```

文をつないで文末の数を減らすと、語尾を言い換えずに解消できます。

文末には時制と確信度が乗っています。「注目されている」を「注目を集めた」に変えると現在の状況が過去になり、「考えられている」を「だろう」に変えると、誰かがそう考えているという伝聞が書き手自身の予測に変わります。文末を変えるときは、この二つを動かしていないかを確かめます。動かさずに解消できないときは、反復を残します。

## 文と文のつながりを意識する

避けたい:

```
オンライン授業は移動の負担が小さい。通学に往復2時間かかる学生もいる。
```

望ましい:

```
オンライン授業は移動の負担が小さい。通学に往復2時間かかる学生もいるからである。
```

順序を入れ替えたり、つなぎの言葉を補ったりして、流れを整えます。ここで足したのは関係を示す言葉だけで、新しい事実は足していません。

次の3文は、つなぎの言葉だけでは結びつきません。

```
レポートの構成は重要である。データの収集には時間がかかった。結論では今後の課題を述べた。
```

「データの収集には時間がかかったが、十分な量を確保できた」のように書けば文はつながります。しかし、十分な量が集まったかどうかは原文に書かれていません。事実を足さずにつながらないときは、書き直さずに、どの文とどの文の関係が読み取れないかを指摘します。
