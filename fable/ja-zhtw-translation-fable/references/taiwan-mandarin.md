# 台湾華語の語彙・表現・文法

台湾華語（台湾で使われる中国語）と大陸普通話の違い、および日本語との翻訳で誤りやすい点をまとめた参照資料です。繁体字で書くだけでは台湾華語にならないことに注意してください。語彙・文法・字体・句読点のすべてで台湾の標準に従います。

## 文法・語法の特徴

- 有 + 動詞で経験や完了を表す言い方が台湾では自然に使われる。我有看過那部影片（あの動画は見たことがある）。大陸の規範文法では避けられる形だが、台湾の話し言葉では標準的。
- 語尾助詞が豊富で、ニュアンスを大きく左右する。喔（軽い念押し・親しみ）、耶（驚き・感嘆）、啦（軽い断定・催促）、欸（呼びかけ・気づき）、齁（同意を求める）。日本語の「よ」「ね」「なあ」に近い働きをするため、くだけた文体の翻訳では適切に使うと自然になる。逆にフォーマルな文書では使わない。
- 不會 が「どういたしまして」の返答として使われる。謝謝 への返しは 不會 や 不客氣。
- 程度表現として 蠻…的（けっこう…だ）、超…（超…）、好…（とても…）が口語でよく使われる。
- 幫 を使った依頼が自然。幫我處理一下（ちょっと対応してもらえますか）。
- 二 と 兩 の使い分け、量詞の使い方は大陸とおおむね共通。

## 字体と表記

- 台湾の標準字体（国字標準字体）を使う。裡（裏ではなく）、為（爲ではなく）、著（着ではなく）、臺/台 はどちらも使われるが一般には 台 が多い。
- 句読点は全角を使う。読点は 、ではなく ，を使い、並列の区切りには 、（頓号）を使う。引用符は 「」『』 を使い、大陸式の “” は使わない。
- 数字は算用数字と漢数字を文脈で使い分ける。日付や金額など事務的な情報は算用数字が普通。
- 注音符号（ㄅㄆㄇ）やピンインの併記は、頼まれない限り不要。

### チャットでよく使う台湾の表現

- 笑死: 笑いの定番。日本語の「草」「わろた」に相当。XD や 哈哈哈 も広く使う。
- 真假: 「マジで?」。真的假的 の略。
- 蝦毀: 「は?何それ」。台湾語由来。
- 母湯: 「だめ、やばい」。台湾語由来。
- 傻眼: 「呆れた、ドン引き」。無言 は「言葉を失う」。
- 好扯/有夠扯: 「ありえない、ひどい」。
- 沒差: 「別にいい、気にしない」。大陸では 无所谓 が普通。
- QQ: 泣いている顔文字。嗚嗚 も泣き声。
- 大大: 上手い人・投稿主への軽い敬称。「〜さん、〜ニキ」に近い。
- 邊緣人: ぼっち。肥宅 は自虐的な「オタク」。
- 數字・注音の略記: 87（白癡、ばか）、94（就是）、ㄏㄏ（呵呵）、ㄎㄎ（くすくす）、ㄉ=的、ㄇ=嗎、ㄅ=吧。くだけたチャットで頻出するので読めることが必要。訳出でこちらから多用はしない。
- 荒い言葉: 幹、靠北、靠腰、三小 は親しい間柄のゲームチャットでは頻出だが、日本語の「くそ」「うぜえ」より強い。日本語からこれらに訳すのは、原文が相応に荒い場合に限る。

### 台湾の相手に使わない大陸スラング

牛逼/nb、卧槽、666、yyds、绝绝子、老铁、给力、小姐姐、内卷、躺平 などは大陸のネットスラングで、使うと出自がすぐに分かる。666（すごい）の代わりに台湾では 太神啦/超強/好猛、牛逼 の代わりに 超猛/很屌（やや粗い）を使う。

## 日中同形異義語

日本語と中国語で字面が同じか近いのに意味がずれる語です。そのまま字を写すと誤訳になります。

| 日本語 | 日本語での意味 | 適切な中文訳 | そのまま写した場合の中文での意味 |
|---|---|---|---|
| 検討 | よく調べて考える | 評估/研議/考慮 | 檢討 は「反省する、過ちを振り返る」 |
| 質問 | たずねること | 提問/問題 | 質問 は「問いただす、詰問する」 |
| 約束 | 取り決め | 約定/約好 | 約束 は「制約する、束縛する」 |
| 勉強 | 学習 | 學習/唸書 | 勉強 は「無理強いする、しぶしぶ」 |
| 迷惑 | 困ること | 困擾/麻煩 | 迷惑 は「惑わす」 |
| 深刻 | 重大で憂慮すべき | 嚴重 | 深刻 は「印象深い、深い」 |
| 心配 | 気がかり | 擔心 | 通じない |
| 大丈夫 | 問題ない | 沒問題/沒關係 | 大丈夫 は「立派な男子」 |
| 愛人 | 不倫相手 | 情婦/情夫/外遇對象 | 台湾で 愛人 は「恋人」寄り、大陸では「配偶者」 |
| 手紙 | 書簡 | 信 | 手紙 は「トイレットペーパー」 |
| 湯 | お湯 | 熱水 | 湯 は「スープ」 |
| 娘 | 自分の女の子ども | 女兒 | 娘 は「母、おばさん」 |
| 先生 | 教師 | 老師 | 先生 は「〜さん（男性の敬称）、夫」 |
| 顔色 | 顔の血色・機嫌 | 臉色 | 顏色 は「色彩」 |
| 結構 | かなり/十分 | 相當/不用了 | 結構 は「構造」 |

## 丁寧さの対応づけ

日本語の敬語と中国語の丁寧表現は一対一に対応しないため、場面ごとに近い温度の表現を選びます。

- です/ます調のビジネス文は、請/麻煩/您 と、婉曲な言い回し（方便的話、不好意思打擾了 など）で丁寧さを出す。中国語に敬語の活用はないので、語彙の選択と前置きで調整する。
- 〜てください は依頼の強さに応じて 請〜、麻煩你〜、可以〜嗎 を使い分ける。可以〜嗎 がいちばん柔らかい。
- お疲れ様です は 辛苦了。よろしくお願いします は場面によって 再麻煩你了（依頼の締め）、請多多指教（初対面）、期待與您合作（ビジネス）などに訳し分ける。決まった一語の対応はない。
- 恐れ入りますが/お手数ですが は 不好意思/麻煩您。台湾では 不好意思 が謝罪にも呼びかけにも広く使われる。
- 中国語から日本語に訳すときは逆に、原文に敬語表現がなくても、場面がビジネスなら日本語側は自然な敬語に整える。原文が 你 でも、日本語で「君」と訳すとぞんざいになりすぎる場合が多い。
